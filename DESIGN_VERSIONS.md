# Davies Wrap Specialist — saved design versions

This file records the website design checkpoints that can be restored or compared later.

## Version 1 — Premium automotive foundation

- Git tag: `design-v1`
- Commit: `2bee28c`
- Design model: dark premium automotive layout
- Primary colour: dark graphite grey with a gloss-black Damascus pattern
- Secondary colour: dark silver
- Accent colours: burnt orange and gold
- Branded Davies logo in the navigation header
- PPF photograph on the services page
- Davies squeegee photograph on the contact page
- Compact glass-style Instagram carousel with full-card mouse tilt
- Dark photographic manifesto and specialist sections
- Redesigned high-contrast contact form and contact information panel
- Smooth section and content reveal animations
- Responsive desktop and mobile layouts

Choose this version for the cleaner, more restrained design before the stronger interactive card treatment was introduced.

## Version 2 — Interactive glow cards

- Git tag: `design-v2`
- Commit: the commit containing this file and the Version 2 changes
- Design model: premium automotive glass with interactive edge lighting
- Everything included in Version 1
- Redesigned “Built around your deadline” section using substantial contact-form-style cards
- Clearer service-card hierarchy, brighter copy and burnt-orange status rails
- Directional mouse-following border glow across non-carousel cards
- Glow treatment added to service cards, rate cards, contact panels, specialist image and service-radius map
- Carousel cards deliberately excluded from BorderGlow so their floating-glass treatment stays distinct
- Stronger navigation click response with larger gooey particles, an impact animation and an expanding ring
- Responsive card layouts for desktop, tablet and mobile
- Updated scroll reveals for the new card structure

Choose this version for the richer, more interactive presentation with stronger visual feedback.

## Switching versions

Ask Codex to switch the website to `design-v1` or `design-v2`. The tags preserve both states, so you do not need to remember the commit codes.
